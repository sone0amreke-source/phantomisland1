# Phantom Island — النسخة التجريبية 0.1

تطبيق أندرويد تجريبي يعرض واجهة عائمة بطابع Phantom Cyber.

## المزايا الحالية
- واجهة عائمة يمكن فتحها وإغلاقها وتحريكها.
- لا يطلب الوصول إلى جهات الاتصال أو الرسائل أو الحسابات أو بيانات البنك.
- يحتاج إذن «الظهور فوق التطبيقات الأخرى» فقط لعرض الجزيرة.
- لوحة الموسيقى تجريبية ولا تتحكم بمشغل الموسيقى حاليًا.

## بناء APK
المشروع يستخدم Android Gradle Plugin 8.6.1 وGradle 8.7 وJava 17. في GitHub Actions شغّل workflow باسم **Build Phantom Island APK**، ثم نزّل artifact باسم **Phantom-Island-debug-APK** من صفحة تشغيل workflow.

## تنبيه
هذه نسخة أولية. لا أستطيع اعتبارها مختبرة على جهازك حتى ينجح البناء وتجربتها فعليًا.
